> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir o RAG vetorial por uma base FTS5 local servida por hook + MCP, com atualização diária a partir do release `kb-latest`, contribuição da comunidade com privacidade verificável e sincronização do mantenedor — tudo rodando sem `npm install` na máquina do usuário.

O índice é um SQLite FTS5 (`node:sqlite`) montado localmente a partir dos `.md` — embutidos no plugin ou baixados do `kb-latest` — e tratado como cache descartável.

**Tech Stack:** Node ≥ 22.13 (`node:sqlite`, FTS5), TypeScript 5.9, vitest 5.0.4, esbuild 0.28.2, `@modelcontextprotocol/sdk` 1.32.1, zod 4.6.7, GitHub Actions, `gh` CLI.

## Review Focus

1. **Windows segurando `kb.db` aberto** (MCP e hook ao mesmo tempo) → o rename do índice novo falha; a busca tem de funcionar mesmo assim, usando a cópia nova. Teste na Task 4.
2. **Prompt com sintaxe que quebra FTS5** (aspas, parênteses, `*`, `-`, `AND`/`OR`/`NOT`/`NEAR`, SQL) → nunca lança exceção. Teste na Task 5.
3. **Cache corrompido ou incompleto** (`current/` sem `meta.json`, ou `meta.json` inválido) → cai no embutido sem erro. Teste na Task 8.
4. **Markdown com BOM e CRLF** (arquivos gravados no Windows) → frontmatter e H1 lidos corretamente; hash calculado sobre os bytes crus. Teste na Task 2.
5. **Payload de hook estranho ou enorme** (sem `prompt`, `prompt` não-string, 100 KB de texto) → nenhuma saída, sem exceção, em menos de 500 ms. Teste na Task 13.

```ts
import * as fs from 'node:fs';
import * as os from 'node:os';
import * as path from 'node:path';
import { fileURLToPath } from 'node:url';

export const REPO = 'adrianosantostreina/delphi-dev';
export const MANIFEST_URL = `https://github.com/${REPO}/releases/download/kb-latest/kb-manifest.json`;
export const KB_DIRS = ['core', 'fmx', 'community'] as const;

const SAFE_KB_PATH = /^(core|fmx|community)\/[A-Za-z0-9._/-]+\.md$/;

/** Relative POSIX path inside knowledge/ that cannot escape it. */
export function isSafeKbPath(rel: string): boolean {
  if (!SAFE_KB_PATH.test(rel)) return false;
  return !rel.split('/').some((segment) => segment === '..' || segment === '.' || segment === '');
}

export function rawFileUrl(commit: string, rel: string): string {
  return `https://raw.githubusercontent.com/${REPO}/${commit}/knowledge/${rel}`;
}

export function dataDir(env: NodeJS.ProcessEnv = process.env): string {
  return env.DELPHI_DEV_DATA || path.join(os.homedir(), '.delphi-dev');
}

export function cacheCurrentDir(data: string): string {
  return path.join(data, 'kb-cache', 'current');
}

export function indexPath(data: string): string {
  return path.join(data, 'kb.db');
}

/** runtime/<bundle>.mjs lives one level below the plugin root. */
export function pluginRootFromModule(moduleUrl: string): string {
  return path.resolve(path.dirname(fileURLToPath(moduleUrl)), '..');
}

export function embeddedKnowledgeDir(root: string): string {
  return path.join(root, 'knowledge');
}

export function readPluginVersion(root: string): string {
  try {
    const raw = fs.readFileSync(path.join(root, '.claude-plugin', 'plugin.json'), 'utf8');
    const version = JSON.parse(raw).version;
    return typeof version === 'string' ? version : 'unknown';
  } catch {
    return 'unknown';
  }
}

/** node:sqlite without a flag needs 22.13+. */
export function nodeSupportsIndex(version: string = process.versions.node): boolean {
  const [major, minor] = version.split('.').map(Number);
  return major > 22 || (major === 22 && minor >= 13);
}
```

```ts
import { createHash } from 'node:crypto';
import * as fs from 'node:fs';
import * as path from 'node:path';
import { KB_DIRS } from './paths';

export type Tier = 'canonical' | 'community';

export interface KbDoc {
  path: string;
  tier: Tier;
  title: string;
  category: string;
  tags: string;
  body: string;
  sha256: string;
  bytes: number;
  frontmatter: Record<string, string>;
}

export interface Snapshot {
  root: string;
  docs: KbDoc[];
  id: string;
}

export function sha256(data: Buffer | string): string {
  return createHash('sha256').update(data).digest('hex');
}

export function parseFrontmatter(raw: string): { frontmatter: Record<string, string>; body: string } {
  const text = raw.replace(/^\uFEFF/, '').replace(/\r\n/g, '\n');
  const match = text.match(/^---\n([\s\S]*?)\n---\n?([\s\S]*)$/);
  if (!match) return { frontmatter: {}, body: text };
  const frontmatter: Record<string, string> = {};
  for (const line of match[1].split('\n')) {
    const kv = line.match(/^([A-Za-z0-9_-]+):\s*(.*)$/);
    if (kv) frontmatter[kv[1]] = kv[2].trim().replace(/^["']|["']$/g, '');
  }
  return { frontmatter, body: match[2] };
}

export function tierForPath(rel: string): Tier | null {
  const first = rel.split('/')[0];
  if (first === 'core' || first === 'fmx') return 'canonical';
  if (first === 'community') return 'community';
  return null;
}

export function snapshotId(files: { path: string; sha256: string }[]): string {
  return sha256(files.map((f) => `${f.path}:${f.sha256}`).sort().join('\n'));
}

function walk(dir: string): string[] {
  if (!fs.existsSync(dir)) return [];
  const out: string[] = [];
  for (const entry of fs.readdirSync(dir, { withFileTypes: true })) {
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) out.push(...walk(full));
    else if (entry.isFile() && entry.name.endsWith('.md') && entry.name !== 'INDEX.md') out.push(full);
  }
  return out;
}

export function readSnapshot(root: string): Snapshot {
  const docs: KbDoc[] = [];
  for (const top of KB_DIRS) {
    for (const file of walk(path.join(root, top))) {
      const rel = path.relative(root, file).split(path.sep).join('/');
      const tier = tierForPath(rel);
      if (!tier) continue;
      const buf = fs.readFileSync(file);
      const { frontmatter, body } = parseFrontmatter(buf.toString('utf8'));
      const h1 = body.match(/^#\s+(.+)$/m);
      docs.push({
        path: rel,
        tier,
        title: frontmatter.title || (h1 ? h1[1].trim() : path.basename(file, '.md')),
        category: frontmatter.category || (top === 'fmx' ? 'fmx' : 'general'),
        tags: frontmatter.tags || '',
        body,
        sha256: sha256(buf),
        bytes: buf.length,
        frontmatter,
      });
    }
  }
  docs.sort((a, b) => (a.path < b.path ? -1 : a.path > b.path ? 1 : 0));
  return { root, docs, id: snapshotId(docs) };
}
```

export interface Section {
  heading: string;
  body: string;
}

export const MAX_SECTION_CHARS = 4000;

function capSection(section: Section): Section[] {
  if (section.body.length <= MAX_SECTION_CHARS) return [section];
  const out: Section[] = [];
  let current = '';
  for (const para of section.body.split(/\n{2,}/)) {
    const pieces = para.length > MAX_SECTION_CHARS
      ? para.match(new RegExp(`[\\s\\S]{1,${MAX_SECTION_CHARS}}`, 'g')) ?? []
      : [para];
    for (const piece of pieces) {
      if (current && current.length + 2 + piece.length > MAX_SECTION_CHARS) {
        out.push({ heading: section.heading, body: current });
        current = '';
      }
      current = current ? `${current}\n\n${piece}` : piece;
    }
  }
  if (current) out.push({ heading: section.heading, body: current });
  return out;
}

export function splitSections(body: string): Section[] {
  const sections: Section[] = [];
  let heading = '';
  let lines: string[] = [];
  let inFence = false;

  const flush = (): void => {
    const text = lines.join('\n').trim();
    if (text || heading) sections.push(...capSection({ heading, body: text }));
    lines = [];
  };

  for (const line of body.replace(/\r\n/g, '\n').split('\n')) {
    if (/^\s*(```|~~~)/.test(line)) inFence = !inFence;
    const h2 = inFence ? null : line.match(/^##\s+(.+?)\s*#*\s*$/);
    if (h2) {
      flush();
      heading = h2[1];
      continue;
    }
    lines.push(line);
  }
  flush();
  return sections.length ? sections : [{ heading: '', body: body.trim() }];
}

```ts
import * as fs from 'node:fs';
import * as path from 'node:path';
import { createRequire } from 'node:module';
import type { DatabaseSync } from 'node:sqlite';
import { splitSections } from './chunk';
import type { Snapshot } from './snapshot';

export const INDEX_SCHEMA = '1';
const TEMP_MAX_AGE_MS = 10 * 60 * 1000;

// Loaded on demand: a static import would crash the Node 18 bundles at startup.
const requireCjs = createRequire(import.meta.url);

export function openDatabase(file: string, readOnly = false): DatabaseSync {
  const sqlite = requireCjs('node:sqlite') as typeof import('node:sqlite');
  return new sqlite.DatabaseSync(file, { readOnly });
}

export function readIndexSnapshotId(dbPath: string): string | null {
  if (!fs.existsSync(dbPath) || !fs.statSync(dbPath).isFile()) return null;
  try {
    const db = openDatabase(dbPath, true);
    try {
      const get = (key: string) =>
        (db.prepare('SELECT value FROM meta WHERE key = ?').get(key) as { value?: string } | undefined)?.value;
      return get('schema') === INDEX_SCHEMA ? get('snapshot_id') ?? null : null;
    } finally {
      db.close();
    }
  } catch {
    return null;
  }
}

export function writeIndex(snapshot: Snapshot, file: string): void {
  const db = openDatabase(file);
  try {
    db.exec(`
      CREATE VIRTUAL TABLE sections USING fts5(
        title, heading, body, tags,
        path UNINDEXED, tier UNINDEXED, category UNINDEXED,
        tokenize = 'unicode61 remove_diacritics 2'
      );
      CREATE TABLE meta (key TEXT PRIMARY KEY, value TEXT);
    `);
    const insert = db.prepare(
      'INSERT INTO sections (title, heading, body, tags, path, tier, category) VALUES (?, ?, ?, ?, ?, ?, ?)',
    );
    const meta = db.prepare('INSERT INTO meta (key, value) VALUES (?, ?)');
    db.exec('BEGIN');
    for (const doc of snapshot.docs) {
      for (const section of splitSections(doc.body)) {
        insert.run(doc.title, section.heading, section.body, doc.tags, doc.path, doc.tier, doc.category);
      }
    }
    meta.run('snapshot_id', snapshot.id);
    meta.run('schema', INDEX_SCHEMA);
    meta.run('built_at', new Date().toISOString());
    db.exec('COMMIT');
  } finally {
    db.close();
  }
}

function removeStaleTemps(dbPath: string): void {
  const dir = path.dirname(dbPath);
  const prefix = `${path.basename(dbPath)}.tmp-`;
  for (const name of fs.readdirSync(dir)) {
    if (!name.startsWith(prefix)) continue;
    const full = path.join(dir, name);
    try {
      if (Date.now() - fs.statSync(full).mtimeMs > TEMP_MAX_AGE_MS) fs.rmSync(full, { force: true });
    } catch {
      // another process may be using it
    }
  }
}

function sleepSync(ms: number): void {
  Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, ms);
}

export function ensureIndex(snapshot: Snapshot, dbPath: string): string {
  if (readIndexSnapshotId(dbPath) === snapshot.id) return dbPath;
  fs.mkdirSync(path.dirname(dbPath), { recursive: true });
  removeStaleTemps(dbPath);
  const tmp = `${dbPath}.tmp-${process.pid}-${Date.now()}`;
  writeIndex(snapshot, tmp);
  for (let attempt = 0; attempt < 3; attempt++) {
    try {
      fs.renameSync(tmp, dbPath);
      return dbPath;
    } catch {
      sleepSync(50);
    }
  }
  // kb.db is held open by another process (Windows): use the fresh copy for this call.
  return tmp;
}
```

```ts
import { openDatabase } from './index';
import type { Tier } from './snapshot';

export interface Hit {
  path: string;
  tier: Tier;
  category: string;
  title: string;
  heading: string;
  snippet: string;
  score: number;
}

export interface SearchOptions {
  limit?: number;
  tier?: Tier;
  minScore?: number;
}

// Calibrated against the real knowledge base in Task 21 (see docs/rag-governance.md).
export const MIN_SCORE = 1.0;
export const STRONG_SCORE = 5.0;
export const SNIPPET_MAX = 400;
const MAX_TERMS = 12;

const STOPWORDS = new Set([
  'como', 'para', 'por', 'que', 'com', 'uma', 'dos', 'das', 'nos', 'nas', 'nao', 'mais', 'isso', 'esse',
  'essa', 'este', 'esta', 'qual', 'quando', 'onde', 'meu', 'minha', 'seu', 'sua', 'pelo', 'pela', 'ser',
  'tem', 'ter', 'faz', 'fazer', 'sobre', 'entre', 'depois', 'antes', 'ainda', 'tambem', 'muito', 'porque',
  'the', 'and', 'for', 'with', 'that', 'this', 'from', 'what', 'how', 'why', 'when', 'where', 'not', 'are',
  'was', 'into', 'your', 'you', 'can', 'does', 'have', 'has', 'but', 'use', 'using',
]);
const COMPILER_CODE = /^[efwh]\d{4}$/;

/** Every term is a quoted bareword, so FTS5 operators and SQL in the prompt are inert. */
export function buildMatchQuery(text: string): string | null {
  const folded = text.normalize('NFD').replace(/[\u0300-\u036f]/g, '').toLowerCase();
  const picked: string[] = [];
  for (const token of folded.match(/[\p{L}\p{N}_]+/gu) ?? []) {
    if (picked.length >= MAX_TERMS) break;
    if (picked.includes(token) || STOPWORDS.has(token)) continue;
    if (token.length < 3 && !COMPILER_CODE.test(token)) continue;
    picked.push(token);
  }
  return picked.length ? picked.map((t) => `"${t}"`).join(' OR ') : null;
}

function truncate(text: string, max: number): string {
  const clean = text.replace(/\s+/g, ' ').trim();
  return clean.length <= max ? clean : `${clean.slice(0, max - 1)}…`;
}

export function searchIndex(dbPath: string, text: string, opts: SearchOptions = {}): Hit[] {
  const query = buildMatchQuery(text);
  if (!query) return [];
  const limit = Math.min(Math.max(opts.limit ?? 3, 1), 5);
  const minScore = opts.minScore ?? MIN_SCORE;
  const db = openDatabase(dbPath, true);
  let rows: Hit[];
  try {
    rows = db.prepare(`
      SELECT path, tier, category, title, heading,
             snippet(sections, 2, '', '', '…', 48) AS snippet,
             -bm25(sections, 5.0, 3.0, 1.0, 4.0, 0.0, 0.0, 0.0) AS score
      FROM sections WHERE sections MATCH ? ORDER BY score DESC LIMIT 50
    `).all(query) as unknown as Hit[];
  } finally {
    db.close();
  }
  const seen = new Set<string>();
  const best = rows.filter((r) => {
    if (r.score < minScore || (opts.tier && r.tier !== opts.tier) || seen.has(r.path)) return false;
    seen.add(r.path);
    return true;
  });
  const ordered = [...best.filter((r) => r.tier === 'canonical'), ...best.filter((r) => r.tier === 'community')];
  return ordered.slice(0, limit).map((r) => ({ ...r, snippet: truncate(r.snippet, SNIPPET_MAX) }));
}

export const PRECEDENCE =
  'Canonical prevalece sobre community; community só complementa. Para o arquivo inteiro, use a ferramenta kb_get com o path.';

export function formatInjection(hits: Hit[]): string {
  if (!hits.length) return '';
  const body = hits
    .map((h) => `[${h.tier}/${h.category}] ${h.path} — ${h.title}${h.heading ? ` › ${h.heading}` : ''}\n${h.snippet}`)
    .join('\n\n');
  return `[DELPHI-DEV KNOWLEDGE]\n(${PRECEDENCE})\n\n${body}\n[/DELPHI-DEV KNOWLEDGE]`;
}
```

```ts
import { isSafeKbPath } from './paths';
import type { Snapshot } from './snapshot';

export interface ManifestFile {
  path: string;
  sha256: string;
  bytes: number;
}

export interface Manifest {
  schema: 1;
  commit: string;
  generatedAt: string;
  pluginVersion: string;
  files: ManifestFile[];
}

export interface FileDiff {
  added: ManifestFile[];
  changed: ManifestFile[];
  removed: string[];
}

export function buildManifest(snapshot: Snapshot, commit: string, pluginVersion: string, now = new Date()): Manifest {
  return {
    schema: 1,
    commit,
    generatedAt: now.toISOString(),
    pluginVersion,
    files: snapshot.docs.map((d) => ({ path: d.path, sha256: d.sha256, bytes: d.bytes })),
  };
}

/** The manifest comes from the network: every path must stay inside knowledge/. */
export function parseManifest(input: unknown): Manifest {
  const m = input as Partial<Manifest> | null;
  if (
    !m || m.schema !== 1 || typeof m.commit !== 'string' || !/^[0-9a-f]{7,40}$/.test(m.commit) ||
    typeof m.generatedAt !== 'string' || typeof m.pluginVersion !== 'string' || !Array.isArray(m.files)
  ) {
    throw new Error('invalid manifest');
  }
  for (const f of m.files) {
    if (
      !f || typeof f.path !== 'string' || !isSafeKbPath(f.path) ||
      typeof f.sha256 !== 'string' || !/^[0-9a-f]{64}$/.test(f.sha256) || typeof f.bytes !== 'number'
    ) {
      throw new Error(`invalid manifest entry: ${JSON.stringify(f)}`);
    }
  }
  return m as Manifest;
}

export function diffFiles(local: ManifestFile[], remote: ManifestFile[]): FileDiff {
  const localHash = new Map(local.map((f) => [f.path, f.sha256]));
  const remotePaths = new Set(remote.map((f) => f.path));
  return {
    added: remote.filter((f) => !localHash.has(f.path)),
    changed: remote.filter((f) => localHash.has(f.path) && localHash.get(f.path) !== f.sha256),
    removed: local.filter((f) => !remotePaths.has(f.path)).map((f) => f.path),
  };
}
```

```ts
import * as fs from 'node:fs';
import * as path from 'node:path';

export interface Config {
  suggestions: 'on' | 'off';
  offline: boolean;
}

export interface State {
  lastCheck: string | null;
  lastResult: string | null;
  remoteCommit: string | null;
  remotePluginVersion: string | null;
}

const EMPTY_STATE: State = { lastCheck: null, lastResult: null, remoteCommit: null, remotePluginVersion: null };
export const LOG_MAX_BYTES = 1024 * 1024;

function readJson(file: string): Record<string, unknown> {
  try {
    const value = JSON.parse(fs.readFileSync(file, 'utf8'));
    return value && typeof value === 'object' ? value : {};
  } catch {
    return {};
  }
}

function writeJson(file: string, value: unknown): void {
  fs.mkdirSync(path.dirname(file), { recursive: true });
  const tmp = `${file}.tmp-${process.pid}`;
  fs.writeFileSync(tmp, JSON.stringify(value, null, 2));
  fs.renameSync(tmp, file);
}

export function readConfig(data: string): Config {
  const raw = readJson(path.join(data, 'config.json'));
  return { suggestions: raw.suggestions === 'off' ? 'off' : 'on', offline: raw.offline === true };
}

export function writeConfig(data: string, patch: Partial<Config>): Config {
  const next = { ...readConfig(data), ...patch };
  writeJson(path.join(data, 'config.json'), next);
  return next;
}

export function readState(data: string): State {
  const raw = readJson(path.join(data, 'state.json'));
  const pick = (key: keyof State) => (typeof raw[key] === 'string' ? (raw[key] as string) : null);
  return {
    lastCheck: pick('lastCheck'),
    lastResult: pick('lastResult'),
    remoteCommit: pick('remoteCommit'),
    remotePluginVersion: pick('remotePluginVersion'),
  };
}

export function writeState(data: string, patch: Partial<State>): State {
  const next = { ...EMPTY_STATE, ...readState(data), ...patch };
  writeJson(path.join(data, 'state.json'), next);
  return next;
}

export function isOffline(data: string, env: NodeJS.ProcessEnv): boolean {
  return env.DELPHI_DEV_KB_OFFLINE === '1' || readConfig(data).offline;
}

export function logError(data: string, where: string, err: unknown): void {
  try {
    const dir = path.join(data, 'logs');
    fs.mkdirSync(dir, { recursive: true });
    const file = path.join(dir, 'kb.log');
    if (fs.existsSync(file) && fs.statSync(file).size > LOG_MAX_BYTES) fs.renameSync(file, `${file}.1`);
    const message = err instanceof Error ? err.stack ?? `${err.name}: ${err.message}` : String(err);
    fs.appendFileSync(file, `${new Date().toISOString()} [${where}] ${message}\n`);
  } catch {
    // logging must never break a hook or a tool call
  }
}
```

```ts
import * as fs from 'node:fs';
import * as path from 'node:path';
import { cacheCurrentDir, embeddedKnowledgeDir } from './paths';

export interface ActiveSource {
  kind: 'embedded' | 'updated';
  dir: string;
  commit: string | null;
}

export interface CacheMeta {
  pluginVersion: string;
  commit: string;
}

export function readCacheMeta(data: string): CacheMeta | null {
  try {
    const raw = JSON.parse(fs.readFileSync(path.join(cacheCurrentDir(data), 'meta.json'), 'utf8'));
    if (typeof raw?.pluginVersion === 'string' && typeof raw?.commit === 'string') {
      return { pluginVersion: raw.pluginVersion, commit: raw.commit };
    }
    return null;
  } catch {
    return null;
  }
}

/**
 * kb-latest is rebuilt on every merge to master and releases come from master, so a
 * cache downloaded for this plugin version is never older than the embedded copy.
 * A plugin update invalidates the cache until the next check refreshes it.
 */
export function resolveActive(root: string, data: string, env: NodeJS.ProcessEnv, pluginVersion: string): ActiveSource {
  const embedded: ActiveSource = { kind: 'embedded', dir: embeddedKnowledgeDir(root), commit: null };
  if (env.DELPHI_DEV_KB_SOURCE === 'embedded') return embedded;
  const meta = readCacheMeta(data);
  if (!meta || meta.pluginVersion !== pluginVersion) return embedded;
  return { kind: 'updated', dir: cacheCurrentDir(data), commit: meta.commit };
}
```

```ts
import * as path from 'node:path';
import { resolveActive } from './active';
import { diffFiles, parseManifest } from './manifest';
import { cacheCurrentDir, MANIFEST_URL, rawFileUrl } from './paths';
import { isOffline, readState, writeState } from './prefs';
import { readSnapshot, sha256 } from './snapshot';

export type Fetcher = (url: string, timeoutMs: number) => Promise<Buffer>;

export const nodeFetcher: Fetcher = async (url, timeoutMs) => {
  const res = await fetch(url, { signal: AbortSignal.timeout(timeoutMs), headers: { 'User-Agent': 'delphi-dev-kb' } });
  if (!res.ok) throw new Error(`HTTP ${res.status} for ${url}`);
  return Buffer.from(await res.arrayBuffer());
};

export const CHECK_INTERVAL_MS = 24 * 60 * 60 * 1000;
export const UPDATE_DEADLINE_MS = 60_000;
const MANIFEST_TIMEOUT_MS = 5_000;
const FILE_TIMEOUT_MS = 15_000;

export interface UpdateOptions {
  root: string;
  data: string;
  env: NodeJS.ProcessEnv;
  pluginVersion: string;
  fetcher?: Fetcher;
  force?: boolean;
  now?: Date;
}

export interface UpdateResult {
  status: 'up-to-date' | 'updated' | 'offline' | 'skipped' | 'failed';
  added: number;
  changed: number;
  removed: number;
  commit: string | null;
  remotePluginVersion: string | null;
  error?: string;
}

export function isCheckDue(data: string, now: Date): boolean {
  const last = readState(data).lastCheck;
  if (!last) return true;
  const at = Date.parse(last);
  return Number.isNaN(at) || now.getTime() - at > CHECK_INTERVAL_MS;
}

function writeInto(dir: string, rel: string, content: Buffer): void {
  const full = path.join(dir, ...rel.split('/'));
  fs.mkdirSync(path.dirname(full), { recursive: true });
  fs.writeFileSync(full, content);
}

function swapIntoCurrent(data: string, staging: string): void {
  const current = cacheCurrentDir(data);
  const old = `${current}-old-${process.pid}-${Date.now()}`;
  if (fs.existsSync(current)) fs.renameSync(current, old);
  try {
    fs.renameSync(staging, current);
  } catch (err) {
    if (fs.existsSync(old)) fs.renameSync(old, current);
    throw err;
  }
  fs.rmSync(old, { recursive: true, force: true });
}

export async function runUpdate(opts: UpdateOptions): Promise<UpdateResult> {
  const { root, data, env, pluginVersion, fetcher = nodeFetcher, force = false, now = new Date() } = opts;
  const none = { added: 0, changed: 0, removed: 0, commit: null, remotePluginVersion: null };
  if (isOffline(data, env)) return { status: 'offline', ...none };
  if (!force && !isCheckDue(data, now)) return { status: 'skipped', ...none };

  const started = Date.now();
  const staging = path.join(data, 'kb-cache', `staging-${process.pid}-${started}`);
  try {
    const manifest = parseManifest(JSON.parse((await fetcher(MANIFEST_URL, MANIFEST_TIMEOUT_MS)).toString('utf8')));
    const active = resolveActive(root, data, env, pluginVersion);
    const local = readSnapshot(active.dir).docs.map((d) => ({ path: d.path, sha256: d.sha256, bytes: d.bytes }));
    const diff = diffFiles(local, manifest.files);
    const counts = {
      added: diff.added.length,
      changed: diff.changed.length,
      removed: diff.removed.length,
      commit: manifest.commit,
      remotePluginVersion: manifest.pluginVersion,
    };
    const remoteState = { lastCheck: now.toISOString(), remoteCommit: manifest.commit, remotePluginVersion: manifest.pluginVersion };

    if (!counts.added && !counts.changed && !counts.removed) {
      writeState(data, { ...remoteState, lastResult: 'up-to-date' });
      return { status: 'up-to-date', ...counts };
    }

    fs.mkdirSync(staging, { recursive: true });
    const changedPaths = new Set(diff.changed.map((f) => f.path));
    const remotePaths = new Set(manifest.files.map((f) => f.path));
    for (const f of local) {
      if (remotePaths.has(f.path) && !changedPaths.has(f.path)) {
        writeInto(staging, f.path, fs.readFileSync(path.join(active.dir, ...f.path.split('/'))));
      }
    }
    for (const f of [...diff.added, ...diff.changed]) {
      if (Date.now() - started > UPDATE_DEADLINE_MS) throw new Error('update deadline exceeded');
      const body = await fetcher(rawFileUrl(manifest.commit, f.path), FILE_TIMEOUT_MS);
      if (sha256(body) !== f.sha256) throw new Error(`sha256 mismatch for ${f.path}`);
      writeInto(staging, f.path, body);
    }
    fs.writeFileSync(path.join(staging, 'manifest.json'), JSON.stringify(manifest, null, 2));
    fs.writeFileSync(path.join(staging, 'meta.json'), JSON.stringify({ pluginVersion, commit: manifest.commit }));
    swapIntoCurrent(data, staging);
    writeState(data, { ...remoteState, lastResult: 'updated' });
    return { status: 'updated', ...counts };
  } catch (err) {
    fs.rmSync(staging, { recursive: true, force: true });
    const message = err instanceof Error ? err.message : String(err);
    // lastCheck stays untouched so the next start retries.
    writeState(data, { lastResult: `failed: ${message}` });
    return { status: 'failed', ...none, error: message };
  }
}
```

```ts
export interface Finding {
  line: number;
  kind: string;
  excerpt: string;
}

interface Rule {
  kind: string;
  pattern: RegExp;
  /** Returns true when the match is a placeholder or documentation value. */
  allow?: (m: RegExpExecArray) => boolean;
}

const PLACEHOLDER = /^(\*+|<[^>]*>|x{3,}|\.{3}|suasenha|yourpassword|your_\w+|sua_\w+|seu_\w+)$/i;
const DOC_IP = /^(127\.0\.0\.1|0\.0\.0\.0|192\.0\.2\.\d+|198\.51\.100\.\d+|203\.0\.113\.\d+)$/;

const RULES: Rule[] = [
  { kind: 'private-key', pattern: /-----BEGIN [A-Z ]*PRIVATE KEY-----/g },
  { kind: 'aws-key', pattern: /\bAKIA[0-9A-Z]{16}\b/g },
  { kind: 'github-token', pattern: /\bgh[pousr]_[A-Za-z0-9]{36,}\b/g },
  { kind: 'npm-token', pattern: /\bnpm_[A-Za-z0-9]{36}\b/g },
  { kind: 'jwt', pattern: /\beyJ[\w-]{10,}\.[\w-]{10,}\.[\w-]{10,}/g },
  {
    kind: 'conn-string',
    pattern: /\b(Password|Pwd)=([^;\s]+)/gi,
    allow: (m) => PLACEHOLDER.test(m[2]),
  },
  {
    kind: 'assignment',
    pattern: /\b(password|passwd|pwd|senha|secret|api[_-]?key|token)\b\s*:?=?\s*[:=]\s*['"]?([^\s'";]{6,}|<[^>]*>)/gi,
    allow: (m) => PLACEHOLDER.test(m[2]),
  },
  {
    kind: 'ipv4',
    pattern: /\b(?:(?:25[0-5]|2[0-4]\d|1?\d?\d)\.){3}(?:25[0-5]|2[0-4]\d|1?\d?\d)\b/g,
    allow: (m) => DOC_IP.test(m[0]),
  },
  {
    kind: 'email',
    pattern: /\b[\w.+-]+@[\w-]+(?:\.[\w-]+)+\b/g,
    allow: (m) => /@(example\.com|exemplo\.com\.br)$/i.test(m[0]),
  },
  { kind: 'cpf', pattern: /\b\d{3}\.\d{3}\.\d{3}-\d{2}\b/g },
  { kind: 'cnpj', pattern: /\b\d{2}\.\d{3}\.\d{3}\/\d{4}-\d{2}\b/g },
  {
    kind: 'abs-path',
    pattern: /[A-Za-z]:\\Users\\([^\\\s]+)|\/(?:home|Users)\/([^/\s]+)/g,
    allow: (m) => /^public$/i.test(m[1] ?? m[2] ?? ''),
  },
];

export function scanText(text: string): Finding[] {
  const findings: Finding[] = [];
  const lines = text.replace(/\r\n/g, '\n').split('\n');
  lines.forEach((content, index) => {
    const kinds = new Set<string>();
    for (const rule of RULES) {
      // assignment duplicates conn-string on lines like "Password=..."
      if (rule.kind === 'assignment' && kinds.has('conn-string')) continue;
      rule.pattern.lastIndex = 0;
      let m: RegExpExecArray | null;
      while ((m = rule.pattern.exec(content)) !== null) {
        if (!rule.allow?.(m)) {
          kinds.add(rule.kind);
          break;
        }
      }
    }
    for (const kind of kinds) findings.push({ line: index + 1, kind, excerpt: content.trim().slice(0, 120) });
  });
  return findings;
}
```

```ts
import * as fs from 'node:fs';
import * as path from 'node:path';

// Source files get a UTF-8 BOM. Forms never do: a BOM before `object` breaks ObjectTextToBinary
// ("Error creating form: Invalid stream format"), and raw UTF-8 without BOM is read as ANSI by the
// resource compiler. Forms are rewritten the way the IDE writes them: #NNN escapes, pure ASCII.
// See knowledge dfm-fmx-sem-bom.md.
const BOM_EXTENSIONS = ['.pas', '.dpr', '.dpk', '.inc'];
const FORM_EXTENSIONS = ['.dfm', '.fmx'];
const UTF8_BOM = Buffer.from([0xef, 0xbb, 0xbf]);

/** Escapes non-ASCII characters inside '...' literals as #NNN (one per UTF-16 code unit). */
export function escapeFormText(text: string): { text: string; nonAsciiOutsideStrings: boolean } {
  let out = '';
  let nonAsciiOutsideStrings = false;
  let i = 0;
  while (i < text.length) {
    const ch = text[i];
    if (ch !== "'") {
      if (ch.charCodeAt(0) > 127) nonAsciiOutsideStrings = true;
      out += ch;
      i++;
      continue;
    }
    i++; // opening quote
    const parts: string[] = [];
    let plain = '';
    const flush = (): void => {
      if (plain) parts.push(`'${plain.replace(/'/g, "''")}'`);
      plain = '';
    };
    while (i < text.length) {
      const c = text[i];
      if (c === "'") {
        if (text[i + 1] === "'") {
          plain += "'";
          i += 2;
          continue;
        }
        i++; // closing quote
        break;
      }
      const code = c.charCodeAt(0);
      if (code > 127) {
        flush();
        parts.push(`#${code}`);
      } else {
        plain += c;
      }
      i++;
    }
    flush();
    out += parts.length ? parts.join('') : "''";
  }
  return { text: out, nonAsciiOutsideStrings };
}

function fixForm(filePath: string, content: Buffer): void {
  if (content.every((b) => b < 128)) return;
  const hadBom = content.subarray(0, 3).equals(UTF8_BOM);
  const { text, nonAsciiOutsideStrings } = escapeFormText(content.subarray(hadBom ? 3 : 0).toString('utf8'));
  // A non-ASCII identifier only parses with the BOM: keep it (load-bearing) and leave the rename to the skills.
  const keepBom = hadBom && nonAsciiOutsideStrings;
  const next = Buffer.concat([keepBom ? UTF8_BOM : Buffer.alloc(0), Buffer.from(text, 'utf8')]);
  if (!next.equals(content)) fs.writeFileSync(filePath, next);
}

export function fixEncoding(filePath: string): void {
  const ext = path.extname(filePath).toLowerCase();
  if (!fs.existsSync(filePath)) return;
  if (FORM_EXTENSIONS.includes(ext)) {
    fixForm(filePath, fs.readFileSync(filePath));
    return;
  }
  if (!BOM_EXTENSIONS.includes(ext)) return;
  const content = fs.readFileSync(filePath);
  if (content.subarray(0, 3).equals(UTF8_BOM)) return;
  fs.writeFileSync(filePath, Buffer.concat([UTF8_BOM, content]));
}

export function extractPatchPaths(patch: string): string[] {
  const out: string[] = [];
  for (const line of patch.replace(/\r\n/g, '\n').split('\n')) {
    const m = line.match(/^\*\*\* (?:Add File|Update File|Move to): (.+?)\s*$/);
    if (m) out.push(m[1]);
  }
  return out;
}

function collectPatches(value: unknown, acc: string[]): void {
  if (typeof value === 'string') {
    if (value.includes('*** Begin Patch')) acc.push(value);
  } else if (Array.isArray(value)) {
    for (const item of value) collectPatches(item, acc);
  } else if (value && typeof value === 'object') {
    for (const item of Object.values(value)) collectPatches(item, acc);
  }
}

/** Claude Code sends tool_input.file_path; Codex sends an apply_patch body. */
export function pathsFromPayload(payload: unknown): string[] {
  const p = payload as { tool_input?: unknown; cwd?: unknown } | null;
  if (!p || typeof p !== 'object') return [];
  const cwd = typeof p.cwd === 'string' ? p.cwd : process.cwd();
  const input = p.tool_input as { file_path?: unknown } | undefined;
  const raw: string[] = [];
  if (input && typeof input === 'object' && typeof input.file_path === 'string') raw.push(input.file_path);
  const patches: string[] = [];
  collectPatches(input, patches);
  for (const patch of patches) raw.push(...extractPatchPaths(patch));
  return [...new Set(raw.map((file) => path.resolve(cwd, file)))];
}

export async function main(input: NodeJS.ReadableStream = process.stdin): Promise<void> {
  try {
    let raw = '';
    for await (const chunk of input) raw += chunk.toString();
    for (const file of pathsFromPayload(JSON.parse(raw))) fixEncoding(file);
  } catch {
    // silent: a hook must never block the user
  }
}
```

```ts
import { resolveActive } from './active';
import { hasExplicitDelphiSignal, isDelphiProjectDir } from './delphi-intent';
import { ensureIndex } from './index';
import { dataDir, indexPath, nodeSupportsIndex, pluginRootFromModule, readPluginVersion } from './paths';
import { logError } from './prefs';
import { formatInjection, MIN_SCORE, searchIndex, STRONG_SCORE } from './search';
import { readSnapshot } from './snapshot';

export interface InjectContext {
  root: string;
  data: string;
  env: NodeJS.ProcessEnv;
  nodeVersion: string;
  pluginVersion: string;
  minScore?: number;
  strongScore?: number;
}

export const HOOK_DEADLINE_MS = 1000;

export function buildInjection(payload: unknown, ctx: InjectContext): string {
  if (!nodeSupportsIndex(ctx.nodeVersion)) return '';
  const p = payload as { prompt?: unknown; cwd?: unknown } | null;
  const prompt = p && typeof p.prompt === 'string' ? p.prompt : '';
  if (!prompt.trim()) return '';
  const explicit = hasExplicitDelphiSignal(prompt);
  if (!explicit && !isDelphiProjectDir(typeof p?.cwd === 'string' ? p.cwd : undefined)) return '';

  const active = resolveActive(ctx.root, ctx.data, ctx.env, ctx.pluginVersion);
  const db = ensureIndex(readSnapshot(active.dir), indexPath(ctx.data));
  const minScore = explicit ? ctx.minScore ?? MIN_SCORE : ctx.strongScore ?? STRONG_SCORE;
  const text = formatInjection(searchIndex(db, prompt, { limit: 3, minScore }));
  if (!text) return '';
  return JSON.stringify({ hookSpecificOutput: { hookEventName: 'UserPromptSubmit', additionalContext: text } });
}

export async function main(): Promise<void> {
  const deadline = setTimeout(() => process.exit(0), HOOK_DEADLINE_MS);
  const root = pluginRootFromModule(import.meta.url);
  const data = dataDir();
  try {
    let raw = '';
    process.stdin.setEncoding('utf8');
    for await (const chunk of process.stdin) raw += chunk;
    const out = buildInjection(JSON.parse(raw), {
      root, data, env: process.env, nodeVersion: process.versions.node, pluginVersion: readPluginVersion(root),
    });
    if (out) process.stdout.write(out);
  } catch (err) {
    logError(data, 'hook-inject', err);
  } finally {
    clearTimeout(deadline);
  }
}
```

```ts
export interface KbContext {
  root: string;
  data: string;
  env: NodeJS.ProcessEnv;
  nodeVersion: string;
  pluginVersion: string;
  fetcher?: Fetcher;

// A type alias (not an interface) so it stays assignable to the SDK's CallToolResult,
// which carries an index signature.
export type ToolText = {
  content: { type: 'text'; text: string }[];
  isError?: boolean;

export interface Health {
  pluginVersion: string;
  remotePluginVersion: string | null;
  node: string;
  indexSupported: boolean;
  source: 'embedded' | 'updated';
  commit: string | null;
  counts: { canonical: number; community: number };
  lastCheck: string | null;
  lastResult: string | null;
  suggestions: 'on' | 'off';
  offline: boolean;
}

export const DEGRADED =
  'Busca indisponível: o delphi-dev precisa de Node 22.13+ para o índice. ' +
  'Procure direto nos .md em ~/.delphi-dev/kb-cache/current/ ou em knowledge/ na raiz do plugin.';

function reply(text: string, isError = false): ToolText {
  return isError ? { content: [{ type: 'text', text }], isError: true } : { content: [{ type: 'text', text }] };
}

export function kbSearch(ctx: KbContext, args: { query: string; limit?: number; tier?: Tier }): ToolText {
  if (!nodeSupportsIndex(ctx.nodeVersion)) return reply(DEGRADED, true);
  const active = resolveActive(ctx.root, ctx.data, ctx.env, ctx.pluginVersion);
  const db = ensureIndex(readSnapshot(active.dir), indexPath(ctx.data));
  const hits = searchIndex(db, args.query, { limit: args.limit ?? 3, tier: args.tier });
  return reply(hits.length ? formatInjection(hits) : 'Nenhum resultado relevante na base delphi-dev.');
}

export function kbGet(ctx: KbContext, args: { path: string }): ToolText {
  if (!isSafeKbPath(args.path)) return reply(`Caminho inválido: ${args.path}`, true);
  const active = resolveActive(ctx.root, ctx.data, ctx.env, ctx.pluginVersion);
  const file = path.join(active.dir, ...args.path.split('/'));
  if (!fs.existsSync(file)) return reply(`Arquivo não encontrado na base: ${args.path}`, true);
  return reply(fs.readFileSync(file, 'utf8'));
}

export function healthOf(ctx: KbContext): Health {
  const active = resolveActive(ctx.root, ctx.data, ctx.env, ctx.pluginVersion);
  const docs = readSnapshot(active.dir).docs;
  const state = readState(ctx.data);
  const config = readConfig(ctx.data);
  return {
    pluginVersion: ctx.pluginVersion,
    remotePluginVersion: state.remotePluginVersion,
    node: ctx.nodeVersion,
    indexSupported: nodeSupportsIndex(ctx.nodeVersion),
    source: active.kind,
    commit: active.commit,
    counts: {
      canonical: docs.filter((d) => d.tier === 'canonical').length,
      community: docs.filter((d) => d.tier === 'community').length,
    },
    lastCheck: state.lastCheck,
    lastResult: state.lastResult,
    suggestions: config.suggestions,
    offline: config.offline || ctx.env.DELPHI_DEV_KB_OFFLINE === '1',
  };
}

export function kbHealth(ctx: KbContext): ToolText {
  return reply(JSON.stringify(healthOf(ctx), null, 2));
}

export async function kbUpdate(ctx: KbContext, args: { force?: boolean }): Promise<ToolText> {
  const result = await runUpdate({
    root: ctx.root, data: ctx.data, env: ctx.env, pluginVersion: ctx.pluginVersion,
    fetcher: ctx.fetcher, force: args.force ?? true,
  });
  const summary = { ...result, installedPluginVersion: ctx.pluginVersion, counts: healthOf(ctx).counts };
  return reply(JSON.stringify(summary, null, 2), result.status === 'failed');
}

export function kbPrefs(
  ctx: KbContext,
  args: { action: 'get' | 'set'; suggestions?: 'on' | 'off'; offline?: boolean },
): ToolText {
  if (args.action === 'get') return reply(JSON.stringify(readConfig(ctx.data)));
  const patch: { suggestions?: 'on' | 'off'; offline?: boolean } = {};
  if (args.suggestions) patch.suggestions = args.suggestions;
  if (typeof args.offline === 'boolean') patch.offline = args.offline;
  return reply(JSON.stringify(writeConfig(ctx.data, patch)));
}

function guarded<A>(ctx: KbContext, name: string, fn: (args: A) => ToolText | Promise<ToolText>) {
  return async (args: A): Promise<ToolText> => {
    try {
      return await fn(args);
    } catch (err) {
      logError(ctx.data, `mcp:${name}`, err);
      return reply(`Erro em ${name}: ${err instanceof Error ? err.message : String(err)}`, true);
    }
  };
}

export function createServer(ctx: KbContext): McpServer {
  const server = new McpServer({ name: 'delphi-dev-kb', version: ctx.pluginVersion });
  server.registerTool('kb_search', {
    description: 'Busca na base de conhecimento Delphi do delphi-dev (canonical prevalece sobre community).',
    inputSchema: {
      query: z.string().min(2),
      limit: z.number().int().min(1).max(5).optional(),
      tier: z.enum(['canonical', 'community']).optional(),
    },
  }, guarded(ctx, 'kb_search', (args: { query: string; limit?: number; tier?: Tier }) => kbSearch(ctx, args)));
  server.registerTool('kb_get', {
    description: 'Devolve um arquivo inteiro da base, pelo path relativo (ex.: core/encoding-utf8-bom.md).',
    inputSchema: { path: z.string() },
  }, guarded(ctx, 'kb_get', (args: { path: string }) => kbGet(ctx, args)));
  server.registerTool('kb_update', {
    description: 'Atualiza a base a partir do release kb-latest e informa se há versão nova do plugin.',
    inputSchema: { force: z.boolean().optional() },
  }, guarded(ctx, 'kb_update', (args: { force?: boolean }) => kbUpdate(ctx, args)));
  server.registerTool('kb_health', {
    description: 'Estado da base: fonte, commit, contagem por tier, última checagem, Node e versões.',
    inputSchema: {},
  }, guarded(ctx, 'kb_health', (_args: Record<string, never>) => kbHealth(ctx)));
  server.registerTool('kb_prefs', {
    description: 'Lê ou grava preferências do delphi-dev (sugestões de contribuição, modo offline).',
    inputSchema: {
      action: z.enum(['get', 'set']),
      suggestions: z.enum(['on', 'off']).optional(),
```

```ts
import { scanText } from './secret-scan';
import { parseFrontmatter } from './snapshot';

export const MIN_CHARS = 200;
export const MAX_CHARS = 8000;
export const VALID_CATEGORIES = ['bugs', 'architecture', 'patterns', 'failures', 'general'];
const REQUIRED_FIELDS = ['title', 'category', 'tags', 'source'];

export function validateCommunityDoc(raw: string): string[] {
  const { frontmatter, body } = parseFrontmatter(raw);
  const errors: string[] = [];
  for (const field of REQUIRED_FIELDS) {
    if (!frontmatter[field]) errors.push(`missing required frontmatter field: ${field}`);
  }
  if (frontmatter.category && !VALID_CATEGORIES.includes(frontmatter.category)) {
    errors.push(`invalid category "${frontmatter.category}" (must be one of ${VALID_CATEGORIES.join(', ')})`);
  }
  const len = body.trim().length;
  if (len < MIN_CHARS) errors.push(`body too short: ${len} chars (min ${MIN_CHARS})`);
  if (len > MAX_CHARS) errors.push(`body too long: ${len} chars (max ${MAX_CHARS})`);
  for (const f of scanText(body)) errors.push(`secret (${f.kind}) at body line ${f.line}: ${f.excerpt}`);
  return errors;
}
```

```ts
export const LEARNING_HEADING = 'Aprendizado / Learning';

/** Issue forms render each field as "### <label>\n\n<value>". */
export function extractLearning(issueBody: string): string | null {
  const text = issueBody.replace(/\r\n/g, '\n');
  const marker = `### ${LEARNING_HEADING}`;
  const start = text.indexOf(marker);
  if (start < 0) return null;
  const after = text.slice(start + marker.length);
  const end = after.search(/\n### /);
  const value = (end < 0 ? after : after.slice(0, end)).trim();
  return value && value !== '_No response_' ? value : null;
}

export function slugify(title: string): string {
  const slug = title
    .normalize('NFD').replace(/[\u0300-\u036f]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .slice(0, 60)
    .replace(/-+$/g, '');
  return slug || 'aprendizado';
}

export function communityFileName(date: Date, slug: string, issue?: number): string {
  const day = date.toISOString().slice(0, 10);
  return `${day}${issue ? `-issue-${issue}` : ''}-${slug}.md`;
}
```

```ts
import * as fs from 'node:fs';
import * as os from 'node:os';
import * as path from 'node:path';
import { parseArgs } from 'node:util';
import { ensureIndex } from './index';
import { communityFileName, extractLearning, slugify } from './issue';
import { buildManifest } from './manifest';
import { contextFromRuntime, healthOf, kbPrefs, kbUpdate } from './mcp-server';
import { readPluginVersion } from './paths';
import { searchIndex } from './search';
import { scanText } from './secret-scan';
import { parseFrontmatter, readSnapshot } from './snapshot';
import { validateCommunityDoc } from './validate';

export interface CliIO {
  out(line: string): void;
  err(line: string): void;
  env: NodeJS.ProcessEnv;
}

const defaultIO: CliIO = {
  out: (line) => process.stdout.write(`${line}\n`),
  err: (line) => process.stderr.write(`${line}\n`),
  env: process.env,
};

const USAGE = [
  'usage: kb-cli <command>',
  '  manifest <knowledgeDir> --commit <sha> --out <file> [--plugin-version <v>]',
  '  validate <file|dir>...',
  '  scan <file>',
  '  similar <file> --knowledge <dir>',
  '  issue-to-file --out-dir <dir> [--date YYYY-MM-DD]   (env ISSUE_BODY, ISSUE_NUMBER, ISSUE_TITLE)',
  '  update [--force]',
  '  health',
  '  prefs get | prefs set [--suggestions on|off] [--offline true|false]',
  '  contribute <file>',
  '  sync [--apply] [--source <dir>] [--knowledge <dir>]',
].join('\n');

function mdFiles(target: string): string[] {
  if (fs.statSync(target).isFile()) return [target];
  return fs.readdirSync(target, { withFileTypes: true }).flatMap((e) => {
    const full = path.join(target, e.name);
    if (e.isDirectory()) return mdFiles(full);
    return e.name.endsWith('.md') && e.name !== 'INDEX.md' ? [full] : [];
  });
}

const posix = (p: string) => p.split(path.sep).join('/');

async function manifest(args: string[], io: CliIO): Promise<number> {
  const { values, positionals } = parseArgs({
    args, allowPositionals: true,
    options: { commit: { type: 'string' }, out: { type: 'string' }, 'plugin-version': { type: 'string' } },
  });
  const dir = positionals[0];
  if (!dir || !values.commit || !values.out) { io.err(USAGE); return 64; }
  const version = values['plugin-version'] ?? readPluginVersion(path.dirname(path.resolve(dir)));
  const m = buildManifest(readSnapshot(dir), values.commit, version);
  fs.writeFileSync(values.out, JSON.stringify(m, null, 2));
  io.out(`manifest: ${m.files.length} files, commit ${m.commit}, plugin ${m.pluginVersion}`);
  return 0;
}

function validate(args: string[], io: CliIO): number {
  if (!args.length) { io.err(USAGE); return 64; }
  let failed = false;
  for (const file of args.flatMap(mdFiles)) {
    const errors = validateCommunityDoc(fs.readFileSync(file, 'utf8'));
    if (errors.length) {
      failed = true;
      io.err(`FAIL ${posix(file)}`);
      for (const e of errors) io.err(`  - ${e}`);
    } else {
      io.out(`OK ${posix(file)}`);
    }
  }
  return failed ? 1 : 0;
}

function scan(args: string[], io: CliIO): number {
  if (!args[0]) { io.err(USAGE); return 64; }
  const findings = scanText(fs.readFileSync(args[0], 'utf8'));
  for (const f of findings) io.out(`line ${f.line} [${f.kind}] ${f.excerpt}`);
  return findings.length ? 2 : 0;
}

function similar(args: string[], io: CliIO): number {
  const { values, positionals } = parseArgs({ args, allowPositionals: true, options: { knowledge: { type: 'string' } } });
  if (!positionals[0] || !values.knowledge) { io.err(USAGE); return 64; }
  const { frontmatter, body } = parseFrontmatter(fs.readFileSync(positionals[0], 'utf8'));
  const query = `${frontmatter.title ?? ''} ${frontmatter.tags ?? ''} ${body.match(/^#\s+(.+)$/m)?.[1] ?? ''}`;
  const dbPath = path.join(fs.mkdtempSync(path.join(os.tmpdir(), 'kb-similar-')), 'kb.db');
  const hits = searchIndex(ensureIndex(readSnapshot(values.knowledge), dbPath), query, { limit: 3, minScore: 0 });
  if (!hits.length) io.out('Nenhum arquivo parecido na base.');
  for (const h of hits) io.out(`- \`${h.path}\` — ${h.title} (score ${h.score.toFixed(2)})`);
  return 0;
}

function issueToFile(args: string[], io: CliIO): number {
  const { values } = parseArgs({ args, options: { 'out-dir': { type: 'string' }, date: { type: 'string' } } });
  const learning = extractLearning(io.env.ISSUE_BODY ?? '');
  const issue = Number(io.env.ISSUE_NUMBER);
  if (!values['out-dir'] || !learning || !Number.isInteger(issue) || issue <= 0) {
    io.err('issue-to-file: missing --out-dir, ISSUE_NUMBER or the "Aprendizado / Learning" section');
    return 1;
  }
  const title = (io.env.ISSUE_TITLE ?? '').replace(/^kb:\s*/i, '');
  const date = values.date ? new Date(`${values.date}T12:00:00Z`) : new Date();
  const file = path.join(values['out-dir'], communityFileName(date, slugify(title), issue));
  fs.mkdirSync(values['out-dir'], { recursive: true });
  fs.writeFileSync(file, learning);
  io.out(posix(file));
  return 0;
}

async function update(args: string[], io: CliIO): Promise<number> {
  const { values } = parseArgs({ args, options: { force: { type: 'boolean' } } });
  const result = await kbUpdate(contextFromRuntime(), { force: values.force ?? true });
  io.out(result.content[0].text);
  return result.isError ? 1 : 0;
}

function prefs(args: string[], io: CliIO): number {
  const { values, positionals } = parseArgs({
    args, allowPositionals: true,
    options: { suggestions: { type: 'string' }, offline: { type: 'string' } },
  });
  const action = positionals[0] === 'set' ? 'set' : 'get';
  const suggestions = values.suggestions === 'on' || values.suggestions === 'off' ? values.suggestions : undefined;
  const offline = values.offline === undefined ? undefined : values.offline === 'true';
  io.out(kbPrefs(contextFromRuntime(), { action, suggestions, offline }).content[0].text);
  return 0;
}

export async function runCli(argv: string[], io: CliIO = defaultIO): Promise<number> {
  const [command, ...rest] = argv;
  switch (command) {
    case 'manifest': return manifest(rest, io);
    case 'validate': return validate(rest, io);
    case 'scan': return scan(rest, io);
    case 'similar': return similar(rest, io);
    case 'issue-to-file': return issueToFile(rest, io);
    case 'update': return update(rest, io);
    case 'health': io.out(JSON.stringify(healthOf(contextFromRuntime()), null, 2)); return 0;
    case 'prefs': return prefs(rest, io);
    default: io.err(USAGE); return 64;
  }
}
```

```ts
import { parseFrontmatter } from './snapshot';

export interface RunResult {
  status: number;
  stdout: string;
  stderr: string;
}

export type Runner = (cmd: string, args: string[]) => RunResult;

export interface ContributeDeps {
  run: Runner;
  openUrl(url: string): void;
  copyToClipboard(text: string): boolean;
  now: Date;
}

export interface ContributeResult {
  via: 'pr' | 'issue';
  url: string;
  clipboard: boolean;
}

export const ISSUE_URL_LIMIT = 7500;

export function buildIssueUrl(title: string, learning: string): { url: string; fits: boolean } {
  const base = `https://github.com/${REPO}/issues/new?template=kb-contribution.yml&title=${encodeURIComponent(`kb: ${title}`)}`;
  const full = `${base}&learning=${encodeURIComponent(learning)}`;
  return full.length <= ISSUE_URL_LIMIT ? { url: full, fits: true } : { url: base, fits: false };
}

function viaGh(raw: string, title: string, run: Runner, now: Date): string | null {
  const gh = (...args: string[]) => run('gh', args);
  if (gh('auth', 'status').status !== 0) return null;
  const user = gh('api', 'user', '--jq', '.login');
  const login = user.stdout.trim();
  if (user.status !== 0 || !login) return null;

  const slug = slugify(title);
  const branch = `kb/${now.toISOString().slice(0, 10)}-${slug}`;
  const file = `knowledge/community/${communityFileName(now, slug)}`;
  const fork = `${login}/delphi-dev`;

  if (gh('repo', 'fork', REPO, '--clone=false').status !== 0) return null;
  if (gh('repo', 'sync', fork, '--source', REPO).status !== 0) return null;
  const base = gh('api', `repos/${fork}/git/ref/heads/master`, '--jq', '.object.sha');
  if (base.status !== 0 || !base.stdout.trim()) return null;
  const steps: string[][] = [
    ['api', '-X', 'POST', `repos/${fork}/git/refs`, '-f', `ref=refs/heads/${branch}`, '-f', `sha=${base.stdout.trim()}`],
    ['api', '-X', 'PUT', `repos/${fork}/contents/${file}`, '-f', `message=kb: ${title}`,
      '-f', `content=${Buffer.from(raw, 'utf8').toString('base64')}`, '-f', `branch=${branch}`],
  ];
  for (const step of steps) if (gh(...step).status !== 0) return null;
  const pr = gh('pr', 'create', '--repo', REPO, '--head', `${login}:${branch}`, '--base', 'master',
    '--title', `kb: ${title}`, '--body', 'Contribuição enviada pelo /contribute-kb do delphi-dev. Revisar antes de mesclar.');
  const url = pr.stdout.trim().split('\n').pop() ?? '';
  return pr.status === 0 && url.startsWith('https://') ? url : null;
}

export function contribute(raw: string, deps: ContributeDeps): ContributeResult {
  const { frontmatter, body } = parseFrontmatter(raw);
  const title = frontmatter.title || body.match(/^#\s+(.+)$/m)?.[1]?.trim() || 'Aprendizado';
  const prUrl = viaGh(raw, title, deps.run, deps.now);
  if (prUrl) return { via: 'pr', url: prUrl, clipboard: false };

  const { url, fits } = buildIssueUrl(title, raw);
  const clipboard = fits ? false : deps.copyToClipboard(raw);
  deps.openUrl(url);
  return { via: 'issue', url, clipboard };
}

export function defaultDeps(): ContributeDeps {
  const run: Runner = (cmd, args) => {
    const r = spawnSync(cmd, args, { encoding: 'utf8', shell: false });
    return { status: r.status ?? 1, stdout: r.stdout ?? '', stderr: r.stderr ?? String(r.error ?? '') };
  };
  return {
    run,
    now: new Date(),
    openUrl(url) {
      const [cmd, args] =
        process.platform === 'win32' ? ['rundll32', ['url.dll,FileProtocolHandler', url]]
        : process.platform === 'darwin' ? ['open', [url]]
        : ['xdg-open', [url]];
      spawn(cmd as string, args as string[], { detached: true, stdio: 'ignore' }).unref();
    },
    copyToClipboard(text) {
      if (process.platform === 'win32') {
        const b64 = Buffer.from(text, 'utf8').toString('base64');
        const script = `Set-Clipboard -Value ([Text.Encoding]::UTF8.GetString([Convert]::FromBase64String('${b64}')))`;
        return run('powershell', ['-NoProfile', '-Command', script]).status === 0;
      }
      const candidates = process.platform === 'darwin' ? [['pbcopy', []]] : [['wl-copy', []], ['xclip', ['-selection', 'clipboard']]];
      for (const [cmd, args] of candidates as [string, string[]][]) {
        const r = spawnSync(cmd, args, { input: text, encoding: 'utf8' });
        if (r.status === 0) return true;
      }
      return false;
    },
  };
}
```

```ts
import * as fs from 'node:fs';
import * as path from 'node:path';
import { sha256 } from './snapshot';

export type SyncAction = 'new' | 'same' | 'changed' | 'conflict' | 'plugin-only';
type Dest = 'core' | 'fmx';

export interface SyncItem {
  name: string;
  dest: Dest;
  action: SyncAction;
}

export type SyncState = Record<string, { dest: Dest; sha256: string }>;

export const EXCLUDED = /^(INDEX|CLAUDE|AGENTS(\.[\w-]+)?)\.md$/i;
export const STATE_FILE = '.sync-state.json';
const IMPORT_HEADING = '## Importados via /sync-kb';

function firstH1(content: string): string {
  return content.replace(/^\uFEFF/, '').match(/^#\s+(.+)$/m)?.[1]?.trim() ?? '';
}

export function classifyDest(name: string, content: string): Dest {
  return /^fmx-/i.test(name) || /\bFMX\b|FireMonkey/i.test(firstH1(content)) ? 'fmx' : 'core';
}

export function readSyncState(knowledgeDir: string): SyncState {
  try {
    return JSON.parse(fs.readFileSync(path.join(knowledgeDir, STATE_FILE), 'utf8'));
  } catch {
    return {};
  }
}

function sourceFiles(sourceDir: string): string[] {
  return fs.readdirSync(sourceDir, { withFileTypes: true })
    .filter((e) => e.isFile() && e.name.endsWith('.md') && !EXCLUDED.test(e.name))
    .map((e) => e.name)
    .sort();
}

function pluginFiles(knowledgeDir: string, dest: Dest): string[] {
  const dir = path.join(knowledgeDir, dest);
  if (!fs.existsSync(dir)) return [];
  return fs.readdirSync(dir).filter((n) => n.endsWith('.md') && n !== 'INDEX.md');
}

export function planSync(sourceDir: string, knowledgeDir: string, state: SyncState): SyncItem[] {
  const items: SyncItem[] = [];
  const names = sourceFiles(sourceDir);
  for (const name of names) {
    const sourceBytes = fs.readFileSync(path.join(sourceDir, name));
    const existing = (['core', 'fmx'] as Dest[]).find((d) => fs.existsSync(path.join(knowledgeDir, d, name)));
    const dest = existing ?? state[name]?.dest ?? classifyDest(name, sourceBytes.toString('utf8'));
    if (!existing) {
      items.push({ name, dest, action: 'new' });
      continue;
    }
    const destHash = sha256(fs.readFileSync(path.join(knowledgeDir, dest, name)));
    const sourceHash = sha256(sourceBytes);
    const action: SyncAction =
      destHash === sourceHash ? 'same' : state[name]?.sha256 === destHash ? 'changed' : 'conflict';
    items.push({ name, dest, action });
  }
  const known = new Set(names);
  for (const dest of ['core', 'fmx'] as Dest[]) {
    for (const name of pluginFiles(knowledgeDir, dest)) {
      if (!known.has(name)) items.push({ name, dest, action: 'plugin-only' });
    }
  }
  return items;
}

function appendToIndex(knowledgeDir: string, dest: Dest, lines: string[]): void {
  if (!lines.length) return;
  const file = path.join(knowledgeDir, dest, 'INDEX.md');
  let content = fs.existsSync(file) ? fs.readFileSync(file, 'utf8') : `# ${dest}\n`;
  if (!content.includes(IMPORT_HEADING)) content = `${content.replace(/\s*$/, '')}\n\n${IMPORT_HEADING}\n`;
  fs.writeFileSync(file, `${content.replace(/\s*$/, '')}\n${lines.join('\n')}\n`);
}

export function applySync(items: SyncItem[], sourceDir: string, knowledgeDir: string, state: SyncState): SyncState {
  const next: SyncState = { ...state };
  const indexLines: Record<Dest, string[]> = { core: [], fmx: [] };
  for (const item of items) {
    if (item.action === 'conflict' || item.action === 'plugin-only') continue;
    const bytes = fs.readFileSync(path.join(sourceDir, item.name));
    if (item.action === 'new' || item.action === 'changed') {
      fs.mkdirSync(path.join(knowledgeDir, item.dest), { recursive: true });
      fs.writeFileSync(path.join(knowledgeDir, item.dest, item.name), bytes);
    }
    if (item.action === 'new') {
      indexLines[item.dest].push(`- [${item.name}](${item.name}) — ${firstH1(bytes.toString('utf8')) || item.name}`);
    }
    next[item.name] = { dest: item.dest, sha256: sha256(bytes) };
  }
  appendToIndex(knowledgeDir, 'core', indexLines.core);
  appendToIndex(knowledgeDir, 'fmx', indexLines.fmx);
  fs.writeFileSync(path.join(knowledgeDir, STATE_FILE), `${JSON.stringify(next, null, 2)}\n`);
  return next;
}
```

```yaml
name: Validate Community Contributions

on:
  pull_request:
    paths:
      - 'knowledge/community/**'

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: actions/setup-node@v4
        with:
          node-version: '22'

      # SHAs and the resulting file list are attacker-controlled on a
      # pull_request trigger, so they are passed via env vars (never
      # interpolated into the shell) and every path is checked against a
      # strict allowlist. The allowlist forbids spaces and shell
      # metacharacters, which makes the later word-split expansion safe.
      - name: Collect changed community files
        id: changed
        env:
          BASE_SHA: ${{ github.event.pull_request.base.sha }}
          HEAD_SHA: ${{ github.event.pull_request.head.sha }}
        run: |
          set -euo pipefail
          mapfile -t paths < <(git diff --name-only --diff-filter=AM "$BASE_SHA" "$HEAD_SHA" -- 'knowledge/community/**/*.md')
          safe=()
          for p in "${paths[@]}"; do
            if [[ "$p" =~ ^knowledge/community/[A-Za-z0-9._/-]+\.md$ ]]; then
              safe+=("$p")
            else
              echo "Rejected unsafe community path: $p"
              exit 1
            fi
          done
          echo "files=${safe[*]}" >> "$GITHUB_OUTPUT"

      - name: Validate frontmatter, size and secrets
        if: steps.changed.outputs.files != ''
        env:
          FILES: ${{ steps.changed.outputs.files }}
        run: |
          set -euo pipefail
          node runtime/kb-cli.mjs validate $FILES

      # Fork PRs get a read-only token, so similar files go to the job summary, not a comment.
      - name: Similar files already in the base
        if: steps.changed.outputs.files != ''
        env:
          FILES: ${{ steps.changed.outputs.files }}
        run: |
          set -euo pipefail
          {
            echo "## Arquivos parecidos já na base"
            for f in $FILES; do
              echo ""
              echo "### \`$f\`"
              node runtime/kb-cli.mjs similar "$f" --knowledge knowledge
            done
          } >> "$GITHUB_STEP_SUMMARY"
```

````markdown
# delphi-contribute

## Idioma

Detecte o idioma da conversa e use-o em tudo que o usuário lê (pt-BR padrão, en-US quando ele
escreve em inglês). O idioma do sistema operacional só desempata quando não há conversa suficiente.
Respeite pedidos explícitos ("respond in English", "responda em português").

## Modos

- **Manual** — o usuário chamou `/contribute-kb`. Opções finais: Aprovar / Recusar.
- **Sugestão** — veio da regra da `delphi-standards`. Antes de qualquer coisa, leia a preferência:
  ferramenta `kb_prefs` com `action: get` (MCP `delphi-dev-kb`); sem MCP, leia
  `~/.delphi-dev/config.json`. Se `suggestions` for `off`, **pare sem dizer nada**.
  Opções finais: Aprovar / Recusar / Não mostrar novamente.

## Protocolo

1. **Escolha um aprendizado** da conversa: o problema não trivial que foi resolvido. Um só.
2. **Redija** neste formato, no idioma da conversa:

   ```markdown
   ---
   title: <frase curta que alguém buscaria>
   category: <bugs | architecture | patterns | failures | general>
   tags: <termos em pt e en separados por vírgula, incluindo códigos de erro>
   source: community
   lang: <pt-BR | en-US>
   ---
   # <título>

   ## Sintoma
   ## Causa
   ## Solução
   ## Exemplo genérico
   ```

   Regras de redação:
   - Use identificadores didáticos (`TCliente`, `FNome`, `ACliente`, `BuscarPorCodigo`). **Nunca**
     nomes de classes, tabelas, units, caminhos, servidores ou empresas do projeto do usuário.
````

````markdown
Detecte o idioma da primeira mensagem. Padrão: pt-BR. Respeite overrides explícitos
("responda em inglês" / "respond in English").

## Regra fundamental — depende do tipo de arquivo

| Arquivo | Encoding | Acento em string |
|---|---|---|
| `.pas` / `.dpr` / `.dpk` / `.inc` | UTF-8 **com** BOM | caractere direto: `'Opção'` |
| `.dfm` / `.fmx` | ASCII puro, **sem** BOM | escape `#NNN`, como o IDE grava: `'Op'#231#227'o'` |

- **Form com BOM** → `Error creating form: Invalid stream format` ao abrir no designer.
- **Form com acento cru (UTF-8 sem BOM)** → o compilador de recursos lê como ANSI e a tela mostra
  "OpÃ§Ã£o".
- **Nome de objeto em form** (`object mnItOpcoes: TMenuItem`) → **sempre ASCII**. Identificador não
  aceita `#NNN`; se encontrar um com acento, renomeie no `.dfm`/`.fmx` **e** no `.pas`.

O hook `PostToolUse` do plugin aplica isso ao gravar: põe BOM em `.pas`/`.dpr`/`.dpk`/`.inc` e
converte acentos de strings de `.dfm`/`.fmx` em `#NNN`. Sem o hook ativo (sem Node), siga a tabela
à mão.

## Referência completa

Consulte a base (`kb_get` com `core/encoding-utf8-bom.md`, ou o arquivo em `knowledge/`) para:
- Diagnóstico de mojibake
- Como verificar e corrigir BOM em arquivos existentes
- `{$CODEPAGE UTF8}` para forçar encoding em units específicas
- Encoding em `TStringList.LoadFromFile` / `SaveToFile`
- Projetos pré-XE2 que precisam de ANSI/CP1252

## Checklist ao criar/editar arquivo Delphi

1. `.pas` novo → BOM (o hook injeta)
2. `.dfm`/`.fmx` novo → sem BOM, acentos de `Caption`/`Text`/`Hint` como `#NNN`, nomes de objeto ASCII
3. Arquivo antigo → conferir os 3 primeiros bytes antes de commitar (`EF BB BF` só em fonte)
4. `TStringList.LoadFromFile` → sempre passar `TEncoding.UTF8` como segundo parâmetro

// CORRETO em .pas — UTF-8 direto (arquivo com BOM)
LMsg := 'Opção selecionada';
````
