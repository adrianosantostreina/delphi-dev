# Guia de Teste — delphi-dev v2.0.1 (npx installer)

## Pré-requisitos no ambiente de teste

| Requisito | Versão mínima | Verificar |
|-----------|--------------|-----------|
| Node.js | 18+ | `node --version` |
| Claude Code CLI | qualquer | `claude --version` |
| git | qualquer | `git --version` |
| VS Code | qualquer | `code --version` (opcional — só avisa se ausente) |

Se **Node.js** ou **Claude Code CLI** ou **git** estiverem faltando, o installer para com mensagem de erro clara indicando o que instalar.

---

## Instalação

```bash
npx delphi-dev
```

### O que o comando faz (em ordem)

1. Verifica pré-requisitos (Node, Claude CLI, git)
2. Clona o plugin em `~/.claude/plugins/delphi-dev`
3. Registra o plugin no Claude Code (`claude plugin install`)
4. Registra os 4 hooks em `~/.claude/settings.json`
5. Tenta baixar `rag.db` da última GitHub Release (v2.0 ainda não tem — mostra aviso, não falha)
6. Instala a extensão VS Code via `code --install-extension adrianosantos.delphi-dev-vscode`
7. Exibe tabela de status final

### Output esperado (máquina com VS Code)


## Verificação pós-instalação

### 1. Verificar status geral

```bash
npx delphi-dev verify
```

### 2. Verificar plugin no Claude Code

```bash
claude plugin list
```
Esperado: `delphi-dev` aparece na lista.

### 3. Verificar hooks registrados

**Windows (PowerShell):**
```powershell
cat "$env:USERPROFILE\.claude\settings.json"
```

**macOS/Linux:**
```bash
cat ~/.claude/settings.json
```

Esperado: JSON com as 4 chaves:
```json
{
  "hooks": {
    "SubagentStop": [...],
    "Stop": [...],
    "UserPromptSubmit": [...],
    "PostToolUse": [...]
  }
}
```

### 4. Verificar extensão VS Code

```bash
code --list-extensions | grep adrianosantos
```
Esperado: `adrianosantos.delphi-dev-vscode`

### 5. Verificar versão no Claude Code

Abrir Claude Code e digitar:
```
/about
```
Esperado: linha com `Versão: 2.0.0`.

## Outros comandos do installer

```bash
npx delphi-dev update      # atualiza plugin + rag.db
npx delphi-dev sync-kb     # baixa rag.db da última release
npx delphi-dev verify      # verifica status da instalação
npx delphi-dev uninstall   # remove hooks (não apaga arquivos)
```
